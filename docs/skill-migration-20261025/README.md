# 昇腾技能从全局迁入项目

日期：2026-10-25，Asia/Shanghai。

已完成从全局迁出。本次处理 12 项同包技能：11 项昇腾/NPU 专用技能，以及原项目文档列作远程 NPU 配套的 `remote-server-guide`。直接和嵌套入口清单包含 57 个用户级技能目录，在其中 41 个目录发现 492 份副本；逐文件 SHA-256 和目录结构比对显示，每项技能的 41 份副本内容完全相同。初次清理的 420 份及独立复查发现的 72 份均已迁出。

目标是本项目的 `.agents/skills/` 与 `.claude/skills/`，各保留完整的 12 项，包含 152 个文件。两个入口均为普通目录，没有指回用户全局目录的链接。

- `manifest.json`：原始全局来源、各技能文件与目录清单、SHA-256、目标入口和迁移状态。
- `global-removal.jsonl`：逐个来源迁出后的记录；全局父目录和其他技能不在移除范围内。
- `verification.json`：迁移完成后的内容检查和全局残留检查。
- `independent-verification.json`：独立复核扩大检查至 319 个技能目录入口，确认目标全局目录和链接均为 0，并核对 304 个文件及 Git 中保存的原始字节。

采用先复制到项目、完整核对并保存 Git 快照，再逐个核验源目录后移除全局副本的顺序。同名文件没有覆盖其他技能，内容没有改写；项目原有代码、模型、运行环境和用户记忆不在迁移范围内。CC Switch 和安装器清单中没有这组技能的注册项，因此未改动这些工具的数据库或配置。

将来需要恢复某个客户端的全局入口时，可根据 manifest 中的原路径，从本项目对应技能目录复制回去；正常使用仅需在本项目开启会话。Claude 或 Codex 已经打开的会话可能仍带有先前加载的描述，重启客户端并新建会话后检查。

本次迁移验证的是文件内容与加载入口，未调用模型验证 safeguard 是否消失。
